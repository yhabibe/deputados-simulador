# Federações na Câmara dos Deputados

Site: **https://yhabibe.github.io/deputados-simulador/**

- `simulador.html` — junte quaisquer listas numa federação e veja as cadeiras por partido e por estado
  e quais partidos passam na cláusula de barreira (o atalho "PT + PSOL/Rede" monta as duas numa lista só)
- `teste_simulador.html` — confere o motor de cálculo do navegador contra o motor de referência

Votos oficiais do TSE para deputado federal (2022 e 2026). Hipótese: cada eleitor vota exatamente como votou.
As páginas são geradas automaticamente a partir de um repositório de análise; não edite aqui.
Cada página é um arquivo único: também funciona baixada e aberta direto no navegador, sem internet.
